## MSBOOST 启动器 v1.0.0

### 下载与使用

1. 下载 `MSBOOST-Launcher-v1.0.0-windows-x64.zip`，解压到一个新文件夹，例如 `D:\MSBOOST\`。
2. 双击 `MSBOOST-Launcher.exe`，在管理员权限提示中点“是”。
3. 在“节点配置”页导入网站下载的配置文件（.json）。回到“加速”页点“开始加速”，然后打开 MapleStory。

节点配置、日志和设置都保存在程序所在的文件夹里，换电脑时复制整个文件夹即可。

### 安全提示

- **SmartScreen**：本程序没有代码签名，Windows 可能提示“Windows 已保护你的电脑”。点“更多信息”，再点“仍要运行”。
- **杀毒软件误报**：程序带有网络分流驱动，并且需要管理员权限，部分杀毒软件可能误报。可以把程序文件夹加入白名单，或者向杀毒软件厂商提交误报。
- **校验文件**：
  - zip 的 SHA-256 见同名的 `.sha256` 文件；
  - 解压后的 `SHA256SUMS.txt` 列出了每个文件的 SHA-256。

### 卸载

先在“设置与关于”页点“清理”，再删除程序所在的文件夹。如果清理报告中有文件“已安排在下次重启电脑时删除”，重启后就会删掉。

### 更新内容

首个正式版本。一个程序完成 MSBOOST 加速，不再需要 BAT 启动器、MSBOOST.exe 和 Netch/Proxifier。

- 只加速 MapleStory 相关程序（包括 Nexon 登录器、反作弊和常见的其他客户端），其他软件一律直连；可选加速 Discord 和 Steam（默认关闭）。
- 一键开始/停止加速，加速中显示已使用流量和当前速率。
- 网络检测：当前到游戏服务器 IPv4、到中转服务器延迟、到游戏服务器延迟；游戏测速目标可以自定义。
- 节点配置：导入网站下载的配置文件，或直接放进程序旁边的 configs 文件夹。
- 托盘图标：关闭窗口后在托盘继续加速，加速中图标变成橙色。
- 日志与诊断包；“清理”可删除驱动、防火墙规则和运行文件。
- 便携版：解压即用，节点配置、日志和设置都在程序文件夹里。
