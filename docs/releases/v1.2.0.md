## MSBOOST 启动器 v1.2.0

**系统要求**：64 位 Windows 10 或 Windows 11（不支持 32 位系统和 ARM 版 Windows）。

### 下载与使用

1. 下载 `MSBOOST-Launcher-v1.2.0-windows-x64.zip`，解压到一个新文件夹，例如 `D:\MSBOOST\`。
2. 双击 `MSBOOST-Launcher.exe`，在管理员权限提示中点“是”。
3. 在“节点配置”页导入网站下载的配置文件（.json）。回到“加速”页点“开始加速”，然后打开 MapleStory。

节点配置、日志和设置都保存在程序所在的文件夹里，换电脑时复制整个文件夹即可。

### 安全提示

- **SmartScreen**：本程序没有代码签名，Windows 可能提示“Windows 已保护你的电脑”。点“更多信息”，再点“仍要运行”。
- **杀毒软件误报**：程序带有网络分流驱动，并且需要管理员权限，部分杀毒软件可能误报。可以把程序文件夹加入白名单，或者向杀毒软件厂商提交误报。
- **校验文件**：
  - zip 的 SHA-256 见同名的 `.sha256` 文件；
  - 解压后的 `SHA256SUMS.txt` 列出了每个文件的 SHA-256。

### 卸载

先在“设置与关于”页点“清理”，再删除程序所在的文件夹。如果清理报告中有文件“已安排在下次重启电脑时删除”，重启后就会删掉。

### 更新内容

- **可以选择用 TCP 还是 UDP 连接节点**：
  - 节点开了 UDP 时，网站下载的配置同时支持 TCP 和 UDP。导入这样的配置后，“加速”页“节点配置”一行的右边会出现 TCP / UDP 切换；“节点配置”页在入口后面标出“支持 UDP”。只支持 TCP 的配置不显示切换，用法和以前一样。
  - 默认用 TCP。选了 UDP 时，开始加速会先用 UDP 试连节点，最多等 5 秒；连不上就自动改用 TCP，并提示“UDP 连不上节点，本次改用 TCP 加速”。设置仍保留 UDP，下次开始时再试。
  - 加速中，状态栏显示实际用的方式：“经 TCP 连接节点”或“经 UDP 连接节点”。加速中不能切换，要先停止。
  - 网络检测按所选方式进行。选 UDP 却连不上节点时，会提示可能是节点没有放行 UDP，或本机网络限制了 UDP，可以改用 TCP。
  - 加速过程中 UDP 断了不会自动切换。停止后重新开始即可，这时连不上 UDP 会自动改用 TCP。
  - 哪种更好要看网络。有的运营商会限制境外 UDP，这时 UDP 反而更慢或会断，请用 TCP。
  - 节点要用 MSBOOST 网站 v2.11.0 新部署，或在网站上“升级节点”后才支持 UDP，之后重新下载配置。经本站中转时，中转规则通过目标校验后才支持 UDP，也要重新下载配置。
- **旧版启动器不要导入支持 UDP 的新配置**：v1.1.2 及更早的版本会把 TCP 和 UDP 混着用，网络限制 UDP 时会有一部分连接失败。请先升级到本版。
- **mieru 升级到 v3.39.0**。

遇到问题时，请在“日志”页点“导出诊断包…”，把诊断包发给 MSBOOST 客服。诊断包里有节点地址，请不要公开发布。
