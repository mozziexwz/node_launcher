## MSBOOST 启动器 v1.1.1

**系统要求**：64 位 Windows 10 或 Windows 11（不支持 32 位系统和 ARM 版 Windows）。

### 下载与使用

1. 下载 `MSBOOST-Launcher-v1.1.1-windows-x64.zip`，解压到一个新文件夹，例如 `D:\MSBOOST\`。
2. 双击 `MSBOOST-Launcher.exe`，在管理员权限提示中点“是”。
3. 在“节点配置”页导入网站下载的配置文件（.json）。回到“加速”页点“开始加速”，然后打开 MapleStory。

节点配置、日志和设置都保存在程序所在的文件夹里，换电脑时复制整个文件夹即可。

### 安全提示

- **SmartScreen**：本程序没有代码签名，Windows 可能提示“Windows 已保护你的电脑”。点“更多信息”，再点“仍要运行”。
- **杀毒软件误报**：程序带有网络分流驱动，并且需要管理员权限，部分杀毒软件可能误报。可以把程序文件夹加入白名单，或者向杀毒软件厂商提交误报。
- **校验文件**：
  - zip 的 SHA-256 见同名的 `.sha256` 文件；
  - 解压后的 `SHA256SUMS.txt` 列出了每个文件的 SHA-256。

### 卸载

先在“设置与关于”页点“清理”，再删除程序所在的文件夹。如果清理报告中有文件“已安排在下次重启电脑时删除”，重启后就会删掉。

### 更新内容

- **诊断信息更完整，方便排查连不上的问题**（加速功能本身没有变化）：
  - 日志新增“连接”分类：加速期间，游戏和登录器连了哪些地址、是否走了加速、交给节点的是域名还是 IP、节点有没有回应；停止加速时附一行统计。只记录游戏相关的程序，其他程序的连接不记；
  - 开始加速时，日志里会记下网络环境（Windows 版本、系统代理、网卡、IPv6 和 DNS）和界面上的提醒；
  - 诊断包里增加网络环境和正在运行的游戏相关程序。

遇到问题时，请在“日志”页点“导出诊断包…”，把诊断包发给 MSBOOST 客服。诊断包里有节点地址，请不要公开发布。
