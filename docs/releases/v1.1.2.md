## MSBOOST 启动器 v1.1.2

**系统要求**：64 位 Windows 10 或 Windows 11（不支持 32 位系统和 ARM 版 Windows）。

### 下载与使用

1. 下载 `MSBOOST-Launcher-v1.1.2-windows-x64.zip`，解压到一个新文件夹，例如 `D:\MSBOOST\`。
2. 双击 `MSBOOST-Launcher.exe`，在管理员权限提示中点“是”。
3. 在“节点配置”页导入网站下载的配置文件（.json）。回到“加速”页点“开始加速”，然后打开 MapleStory。

节点配置、日志和设置都保存在程序所在的文件夹里，换电脑时复制整个文件夹即可。

### 安全提示

- **SmartScreen**：本程序没有代码签名，Windows 可能提示“Windows 已保护你的电脑”。点“更多信息”，再点“仍要运行”。
- **杀毒软件误报**：程序带有网络分流驱动，并且需要管理员权限，部分杀毒软件可能误报。可以把程序文件夹加入白名单，或者向杀毒软件厂商提交误报。
- **校验文件**：
  - zip 的 SHA-256 见同名的 `.sha256` 文件；
  - 解压后的 `SHA256SUMS.txt` 列出了每个文件的 SHA-256。

### 卸载

先在“设置与关于”页点“清理”，再删除程序所在的文件夹。如果清理报告中有文件“已安排在下次重启电脑时删除”，重启后就会删掉。

### 更新内容

- **网络检测新增“本机 DNS 解析游戏域名”**：
  - 检查这台电脑能不能解析 MapleStory 登录、反作弊等要用的 Nexon 域名。
  - 解析失败时，会再用公共 DNS（223.5.5.5、119.29.29.29）查一次做对照：
    - 公共 DNS 能解析，说明问题出在本机 DNS（常见于路由器），界面会提示把网卡的 DNS 改成这两个公共 DNS，或者重启路由器；
    - 公共 DNS 也解析不了，会提示可能是网络没有连通，或者 Nexon 的服务出了问题。
  - 检测失败时，“加速”页顶部也会出现提示。
  - 为什么要查：MSBOOST 加速的是游戏的连接，不接管 DNS 查询。本机 DNS 解析不了这些域名时，游戏根本不会发起连接：登录器一直转圈、游戏登录不了，或者玩一段时间后被反作弊断开。这种情况开加速也帮不上忙，要先修好 DNS。
- **诊断包加入 DNS 检测结果**：导出诊断包时会做一次 DNS 检测，结果写进 `system.txt`。导出时要多等几秒，按钮会显示进行中。

遇到问题时，请在“日志”页点“导出诊断包…”，把诊断包发给 MSBOOST 客服。诊断包里有节点地址，请不要公开发布。
