# v1.1.0：Netch 式小窗口

## 1. 改了什么

### 窗口和布局

- 窗口从 1040×700 缩小到 776×337，内容区约 760×298，和 Netch（约 756×333）差不多大。也和 Netch 一样是固定大小：不能拖动调整，也没有最大化按钮。
- 左侧导航改成顶部标签页：加速、节点配置、网络检测、游戏与加速项、日志、设置与关于。标签栏右侧是版本号和 MSBOOST 主页链接。
- 底部新增状态栏，切到任何页面都显示：
  - 加速中：已运行、已使用流量、上行和下行速率。数值都预留了最长宽度，变化时不会跳动；
  - 未加速、开始中、停止中：显示状态；
  - 右侧是当前节点配置。

### 加速页

- 一组三行：
  - 节点配置：下拉选择，旁边是“管理”；
  - 可选加速：Discord、Steam 开关。鼠标停在上面会显示原来的说明，比如 Steam 下载会消耗节点流量；
  - 网络检测：一行概要，内容是“MSBOOST IPv4、中转延迟、游戏延迟”，右边是“重新检测”小按钮和“详情”链接。
- 下面是加速状态和开始/停止按钮。这一栏固定在页面底部，提示条再多也看得到按钮。
- 概要的各种状态：
  - 未检测显示“—”；
  - 检测中显示“正在检测 MSBOOST IPv4 和延迟…”；
  - 失败时显示红色的“超时”“失败”或“查询失败”，原因写在网络检测页。

### 游戏与加速项页

- 顺序改成：游戏测速目标、可选加速、加速对象。

### 网络检测页

- 新增标签页，保留完整的三项说明：当前到游戏服务器 IPv4、当前到中转服务器延迟、当前到游戏服务器延迟，以及测速目标和成功次数。
- 和首页概要显示的是同一次检测结果；在任一处检测，两边都会更新。

### 其他页面

- 整体收紧：正文 14px → 13px，卡片、按钮、输入框、提示条都变小。
- 内容放不下时在页内滚动，比如加速名单、日志、设置与关于。
- 对话框不会超出窗口，内容多时可以滚动，比如开源许可。

## 2. 设计过程

2026-10-19 先做了两个参考方案：
- 方案一：保留侧边栏的紧凑版，800×520；
- 方案二：Netch 式，760×330。

选了方案二后，又比较了网络检测的三种排法：A 上下排列、B 左右两栏、C 单独一页，最后选定 C。根据反馈做了这些调整：
- 首页概要写“MSBOOST IPv4”；
- “重新检测”用小按钮，“详情”用链接；
- 网络检测页沿用原来的三项完整说明。

## 3. 实测步骤

1. 打开程序：窗口大小和 Netch 差不多，不能拖动调整大小，也没有最大化按钮；各个标签页都能切换，内容放不下时可以滚动。
2. 未加速时：
   - 底部状态栏显示“未加速”和当前节点配置；
   - 点“开始检测”，概要显示三项结果；
   - 点“详情”进入网络检测页，三项说明完整，结果和首页一致。
3. 开始加速：状态栏显示已运行、已使用流量和速率，数值变化时布局不跳。
4. 开着 ProxyBridge：红色提示和“停止 ProxyBridge”按钮正常，底部的“开始加速”按钮仍然看得到。
5. 对话框：停止加速确认、开源许可等都显示完整。
6. 托盘、点 × 最小化到托盘等行为和以前一样。
